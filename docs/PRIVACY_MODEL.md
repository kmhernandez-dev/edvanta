# Modelo de privacidad

## Finalidades

Cada campo debe organizar, educar, preparar consulta, crear seguimiento o facilitar atencion autorizada. No se solicita documento de identidad en el MVP.

## Consentimiento granular

Servicio digital, datos personales y datos sensibles son esenciales. Comunicaciones, compartir con profesionales, calidad/investigacion anonimizada y contenido comercial son independientes. Rechazar opciones no bloquea el portal.

## Derechos y controles

El centro de privacidad permite revisar versiones, revocar opciones, exportar datos y solicitar cierre. La eliminacion efectiva y sus excepciones de retencion deben ser definidas juridicamente antes del lanzamiento real.

## Minimizacion

No se recopilan documentos, geolocalizacion precisa, contactos de terceros completos ni datos profesionales no necesarios. La IP solo se conservara cuando infraestructura y base legal lo justifiquen.
