# Gestión de Calidad Farmacéutica: cómo documentar lo aprendido

La evidencia se produce clase por clase. Esta tabla convierte las clases reales de [Curso de Gestión de Calidad Farmacéutica](/curso-de-gestion-de-calidad-farmaceutica) en evidencias verificables, sin exagerar resultados clínicos.

> **Curso:** [Curso de Gestión de Calidad Farmacéutica](/curso-de-gestion-de-calidad-farmaceutica). Primera unidad gratis; certificado al completar el programa.

1. Elige una clase y un problema real.

3. Aplica una acción pequeña, registra el resultado y pide retroalimentación.

## Preguntas frecuentes

### ¿El certificado es suficiente?

No. Acompáñalo con evidencia de aplicación.

### ¿Puedo usar un caso real?

Sí, con datos anonimizados.

### ¿Qué hago si no tengo trabajo?

Usa un caso del curso o una actividad voluntaria.
