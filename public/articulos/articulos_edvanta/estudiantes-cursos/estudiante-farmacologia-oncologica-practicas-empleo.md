# Farmacología Oncológica: prácticas, primer empleo y portafolio

Un curso no reemplaza la experiencia, pero puede convertirte en un candidato que ya sabe hablar de procesos, evidencia y límites. Esta guía usa las clases de [Curso de Farmacología Oncológica](/curso-de-farmacologia-oncologica) para construir un portafolio pequeño.

> **Curso:** [Curso de Farmacología Oncológica](/curso-de-farmacologia-oncologica). Primera unidad gratis; certificado al completar el programa.

1. Una nota de una página sobre un tema del curso.
2. Un caso resuelto con decisión y evidencia.
3. Una lista de verificación para una tarea real.

## Preguntas frecuentes

### ¿El certificado basta para conseguir empleo?

No. Ayuda, pero la evidencia y la entrevista pesan más.

### ¿Puedo usar casos del curso?

Sí, con datos anonimizados y explicando qué aprendiste.

### ¿Qué hago si no tengo experiencia?

Convierte un trabajo académico o una actividad voluntaria en una evidencia bien contada.
