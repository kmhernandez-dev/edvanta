# Cómo preparar el parcial de Registro Sanitario de Productos Fitoterapéuticos

El parcial de Registro Sanitario de Productos Fitoterapéuticos no se aprueba leyendo el temario una vez. Se aprueba cuando puedes explicar cada unidad, resolver un caso y justificar una decisión. Este plan usa las 31 clases del curso [Curso de Registro Sanitario de Productos Fitoterapéuticos](/curso-de-registro-sanitario-de-productos-fitoterapeuticos) y los recursos relacionados.

> **Curso:** [Curso de Registro Sanitario de Productos Fitoterapéuticos](/curso-de-registro-sanitario-de-productos-fitoterapeuticos). Primera unidad gratis; certificado al completar el programa.

## Preguntas frecuentes

### ¿Necesito memorizar todo?

No. Necesitas explicar el criterio y aplicarlo. La memoria ayuda, pero sin casos no alcanza.

### ¿El curso reemplaza la materia?

No. El curso complementa la materia con práctica y evaluación; la universidad define el programa oficial.

### ¿Qué hago si me queda poco tiempo?

Prioriza las unidades con más peso, resuelve un caso por unidad y revisa las preguntas falladas.
